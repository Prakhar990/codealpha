3. script.js

No React.

No backend.
No framework.

To add an ID, edit the "certificates" object in script.js.

Example:

"CA/12345": {
  name: "Rahul Sharma",
  domain: "Web Development",
  startDate: "1 August 2026",
  endDate: "30 August 2026"
}

Then open:

index.html?id=CA/12345

The page will automatically display the corresponding details.

For local testing, you can simply open index.html in the browser.
